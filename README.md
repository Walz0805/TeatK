# 糖糖大战坑坑鱼

纯前端网页小游戏，直接打开 `index.html` 就能玩。

## 这次调整

- 开局坑坑数量从很多只改成了 **4 只**，后续按节奏慢慢补怪。
- 坑坑整体游速明显调慢，不会一开局就围殴。
- 角色改成 **直接使用生成的人脸鱼身动作图**，不是简单的人脸贴鱼身。
- 糖糖 / 坑坑 都有 4 个动作状态：
  - 待机
  - 游动
  - 攻击蓄力
  - 张嘴咬击
- 增加了更明显的 **吃掉动作**：击败坑坑后，会被吸到糖糖嘴边再消失。

## 操作

- 手机端：左下角摇杆移动，右下角 `咬！` 按钮攻击。
- 电脑端：`WASD` / 方向键移动，`空格` 攻击。

## v4 手机爽玩版调整

- 主要按手机竖屏适配，增加 `viewport-fit=cover`，适配刘海屏 / 底部安全区。
- 摇杆和攻击按钮改为手机上更大的自适应尺寸。
- 玩家移动惯性降低，更好控，不容易飘。
- 坑坑数量减少，刷新更慢，移动更慢。
- 坑坑攻击欲望降低，基本让糖糖追着坑坑咬。
- 糖糖攻击范围、伤害、回血都提高，更适合发泄和爽玩。


## v5 横屏爽玩版调整

- 改为横屏优先：手机竖屏会提示“横屏玩更爽”。
- 横屏下 UI 更紧凑，血条、分数、摇杆、攻击键不会挡住主要战斗区域。
- 横屏下角色显示尺寸更合适，视野更宽，更适合追着坑坑咬。
- 手机按住“咬！”可以连续攻击，不用一直狂点。
- 坑坑进一步减速，玩家仍然占主导。


## v6 野蛮横屏版

- 如果当前屏幕宽 > 高：按正常横屏运行。
- 如果当前屏幕高 > 宽：整个游戏页面会强制旋转 90°，同时游戏逻辑尺寸按横屏计算。
- 竖屏浏览器也不再用全屏遮罩挡住开始按钮。
- 摇杆在强制旋转模式下做了方向修正，尽量保持“看到的方向”和“操作方向”一致。
